DailyLove Backups

A private administration tool that stores encrypted DailyLove database backups in the administrator’s Google Drive. It is operated by the DailyLove administrator; it is not an App user login service.

What the tool does

It uploads encrypted backup files to a dedicated Drive folder, reads them back to check delivery, and retains recent daily, weekly and release backups. The tool also checks available Drive space and alerts the administrator when a backup fails.

Database backups contain application records, account recovery information, database permissions and image references. Photo file contents are excluded.

Google access

Only the administrator connects a Google account. Drive access is requested to manage backups in the existing dedicated folder. The Drive permission itself covers account files; the tool’s configured root folder limits its normal operations, not the OAuth permission.
